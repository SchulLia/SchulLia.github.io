# Aufgabenliste

> **Was passiert hier?** Eckige Klammern verwandeln eine normale Liste in eine Aufgabenliste. `[x]` markiert einen erledigten, `[ ]` einen offenen Eintrag.

- [x] erledigt
- [ ] offen
- [ ] noch offen
