# Text markieren

**Markiere** das Nomen rot und das Verb blau.

<div class="markerquiz">
@markred(Haus)
@markblue(laufen)
@TextmarkerQuiz
</div>

**********
„Haus“ wird rot markiert, „laufen“ blau.
